# Функционал music.xima

Что реализовано в коде на 14 августа 2026. Статусы честные:

- **Работает** — код написан, собран и проверен на устройстве.
- **Собрано** — код написан и компилируется, но на живых данных не проверялся.
- **Заглушка** — есть экран/вызов, но сквозной сценарий не проверялся ни разу.

14 августа 2026 прошёл первый запуск с реальной музыкой на Pixel 8a: скан
MediaStore и старт воспроизведения проверены, дальше приложение упало
([BUGS.md](./BUGS.md) B7). Всё, что за этой границей, по-прежнему **Собрано**,
а не «Работает».

## 1. Воспроизведение

Движок нативный: **Media3 / ExoPlayer** внутри `MediaSessionService`.
В WebView нет ни одного `<audio>` — это проверяется автоматически (см. §7).

| Возможность | Статус | Где живёт |
| --- | --- | --- |
| Play / Pause / Stop / Next / Previous | Собрано | `PlaybackController.kt` |
| Seek, переход к элементу очереди (`skipTo`) | Собрано | `PlaybackController.kt` |
| Shuffle, Repeat (`OFF` / `ALL` / `ONE`) | Собрано | `PlaybackController.kt` |
| Громкость и скорость воспроизведения | Собрано | `PlaybackController.kt` |
| Фоновое воспроизведение при выключенном экране | Собрано | `PlaybackService.kt` |
| Управление с экрана блокировки и из шторки | Собрано | `MediaSession` + системная нотификация |
| Bluetooth и кнопки гарнитуры | Собрано | даёт `MediaSession` |
| Пауза при отключении наушников | Собрано | `setHandleAudioBecomingNoisy(true)` |
| Аудиофокус (звонок, другое приложение) | Собрано | `AudioAttributes` + `handleAudioFocus` |
| Тикер позиции ~500 мс во время игры | Собрано | `PlaybackController.kt` |

**Проверено на устройстве:** трек из библиотеки играет — `MediaSession` отдаёт
`PLAYING`, позиция идёт, трек доигрывает до конца.
**Не проверено:** нотификация и экран блокировки, Bluetooth, фон при выключенном
экране, аудиофокус.

## 3. Библиотека

Источники: **MediaStore** (общая медиатека телефона) и **SAF** — папка, которую
пользователь выбирает сам через `ACTION_OPEN_DOCUMENT_TREE`. Доступ к папке
сохраняется через persistable URI permission. Треки адресуются `content://` URI,
абсолютных путей нет нигде.

| Возможность | Статус |
| --- | --- |
| Полное и инкрементальное сканирование | **Работает** (MediaStore) |
| Прогресс сканирования событием в UI | Собрано |
| Разделы: Песни / Альбомы / Исполнители / Жанры / Папки | Собрано |
| Экраны альбома, исполнителя, жанра, папки | Собрано |
| Сортировки (11 вариантов `TrackSort`) | Собрано |
| Виртуализованный список — рассчитан на 10 000+ треков | **Работает** |
| Постраничная подгрузка по 200 треков | Собрано |
| Извлечение и кэширование обложек (512 px, JPEG) | Собрано |
| Пустые состояния с переходом в настройки | **Работает** |

Обложка кэшируется одна на альбом (ключ от `album + albumArtist`), а не на трек —
иначе на 300 треков было бы 300 копий одной картинки.

## 4. Плейлисты

| Возможность | Статус |
| --- | --- |
| Создать, переименовать, удалить | Собрано |
| Добавить треки, удалить по позиции, переставить | Собрано |
| Обложка-мозаика 2×2 из первых треков | Собрано |
| Боттом-шит «Добавить в плейлист» | Собрано |

Позиции в плейлисте всегда плотные `0..n-1`. Перестановка идёт через временное
отрицательное смещение — иначе `PRIMARY KEY (playlist_id, position)` ловил бы
конфликт уникальности на полпути.

## 5. Умные плейлисты

Правило — это **данные**, которые компилируются в SQL, а не отдельный метод на
каждый пресет. 11 типов правил: `PLAY_COUNT`, `NEVER_PLAYED`,
`LAST_PLAYED_BEFORE_DAYS`, `ADDED_WITHIN_DAYS`, `FAVORITE`, `YEAR_BETWEEN`,
`BITRATE_AT_LEAST`, `DURATION_BETWEEN_MS`, `GENRE_IS`, `ARTIST_IS`,
`TITLE_CONTAINS`.

| Возможность | Статус |
| --- | --- |
| 7 пресетов, засеянных миграцией | **Работает** — видны на устройстве |
| Редактор правил с полями под каждый тип | Собрано |
| Режим «все условия» / «любое условие» | Собрано |
| Сортировка и лимит выборки | Собрано |
| Живой предпросмотр результата (дебаунс 400 мс) | Собрано |

Пресеты: «Недавно добавленные», «Ни разу не играли», «Забытые», «Избранное»,
«Часто слушаю», «2020-е», «Высокое качество». Они лежат строками в таблице
`smart_playlists`, поэтому пользователь может их менять и удалять как обычные.
Английские имена из сида `0001` переименовывает миграция `0002` — применённую
миграцию править нельзя, у sqlx на неё контрольная сумма.

## 6. Поиск, история, подборки

| Возможность | Статус |
| --- | --- |
| Поиск по трекам через SQLite **FTS5** | Собрано |
| Поиск по альбомам, исполнителям, плейлистам | Собрано |
| История последних 10 запросов | Собрано |
| История прослушиваний | Собрано |
| Счётчики проигрываний | Собрано |
| Подборки «Часто слушаете», «Ни разу не играли», «Забытые» | Собрано |
| Главная — вся музыка одним списком | **Работает** |

Экрана статистики (топы и разрезы Today / Week / Month / Year) в продукте нет —
решение от 14 августа 2026. История и счётчики остались: на них держатся
подборки и умные плейлисты (`PLAY_COUNT`, `NEVER_PLAYED`, `FAVORITE`).

Прослушивание засчитывается, если проиграно **не меньше 30 секунд или половины
трека**. Иначе перелистывание подряд накрутило бы счётчики.

Историю пишет **Rust**, получив событие `completed` от нативного слоя, а не
фронтенд. Если убить приложение свайпом, счётчик всё равно корректен.

## 7. Архитектурные гарантии

Проверяются автоматически, все зелёные:

| Инвариант | Как проверяется |
| --- | --- |
| Нет `<audio>` / `HTMLAudioElement` во фронтенде | grep по `src/` |
| `invoke` вызывается только из `src/shared/ipc` | grep по `src/` |
| Нет `any` / `as any` / `@ts-ignore` | grep + `tsc` со строгими флагами |
| SQL только в `infrastructure/sqlite` | grep по `src-tauri/` |
| Нет `todo!()` / `unimplemented!()` | grep по `src-tauri/`, `tauri-plugin-player/` |

## 9. Чего нет совсем

Вне продукта по решению от 14 августа 2026 — не планируются:

- Светлая тема и выбор темы (приложение всегда тёмное).
- Настройка размера сетки.
- Экран статистики (топы и разрезы по периодам).
- Android Auto.
- Сон-таймер.
- Эквалайзер.
- Тексты песен.

Просто ещё не сделано:

- Кроссфейд с наложением дорожек (сейчас `crossfadeMs` даёт плавное затухание
  хвоста и нарастание следующего трека на одном ExoPlayer, без перекрытия), gapless.
- Редактирование тегов.
- Импорт и экспорт плейлистов (m3u).
- Запрос разрешения `READ_MEDIA_AUDIO` в рантайме — объявлено в манифесте,
  но нигде не запрашивается (см. [BUGS.md](./BUGS.md) B6).
- Release-сборка и подпись APK — собирается только debug.
